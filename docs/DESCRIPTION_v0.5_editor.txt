Take your setup with you. BeamNG already syncs your main game settings via Steam Cloud, and even your own vehicle configs - but not your key bindings or graphics settings. This UI app puts them into the game's Steam Cloud folder (settings/cloud), so you can restore them on another PC or on a cloud gaming service like Boosteroid.

[ATTACH=full]1351974[/ATTACH]

Playing on Boosteroid or another cloud gaming service?
Every session starts like a fresh install - your settings AND your mods are gone, including this one (subscribing doesn't help). Set it up once, then each session takes 20 seconds:
- Once: install the mod, add the app, tick "Auto-import at game start" and "Auto-export changes", then click "Export". You can minimize the app or remove it from your UI afterwards.
- Every new session: find "Settings Cloud Sync" in the repository and activate it. That's it - your key bindings and graphics settings are restored automatically, no restart needed. Changes you make are saved automatically within a minute.
- Quit the game via the menu, so Steam can upload your settings.
Tested on Boosteroid with BeamNG.drive 0.40.5.

How to use (two PCs)
1. Add the "Settings Cloud Sync" app to your UI (UI Apps > Add app).
2. Tick what you want to sync and click "Export". Quit the game via the menu so Steam can upload the cloud folder.
3. On the other machine: start the game, tick the same boxes and click "Import". Most settings apply right away.
Export and Import are also in the radial menu under "Settings Cloud Sync", so the app doesn't have to stay on screen. Use the "-" button to minimize it.

Auto-import
Tick "Auto-import at game start" once. A fresh machine uses the profile that was active when you ticked it. From then on, the mod restores your backup automatically whenever the cloud backup is newer than the settings on that machine - ideal for cloud gaming, where every session starts fresh.

Auto-export
Tick "Auto-export changes" once. The mod then saves your settings by itself within a minute after you change something, and when you quit. For safety it only starts after this machine has imported or exported once, so a fresh session can never overwrite your backup with default settings.

Profiles
Playing on different machines with different hardware? Create a profile per machine (e.g. "Desktop", "Laptop", "Boosteroid") and pick it in the app. Each profile has its own backup, so your laptop never gets your desktop's graphics settings. The profile choice is stored only on that machine.

Backup history
Your 3 previous backups (per profile) are kept, each labelled with date and PC name. Something went wrong? Pick an older backup in the app or in the radial menu ("Restore older backup"). It becomes your current backup again, and the one you replaced moves into the history - nothing gets lost.
Auto-export adds only one history entry per session.
An export never replaces your saved key bindings with "nothing".
Before importing, your current local files are also saved to settings/settingsCloudSync_preImport.

What can be synced
- Controls & key bindings, keyboard and controller (settings/inputmaps)
- Other settings files in your user folder (graphics, UI layouts etc.)

Console: settingsCloudSync.exportAll() / settingsCloudSync.importAll()
settingsCloudSync.setProfile('Laptop')
Only text files from your own user folder are copied; nothing leaves your Steam account.
